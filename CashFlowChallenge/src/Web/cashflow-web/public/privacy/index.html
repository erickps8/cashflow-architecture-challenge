Política de Privacidade — CashFlow

Última atualização: 5 de setembro de 2026.

O CashFlow é um aplicativo de gestão financeira pessoal. Esta política explica, de forma resumida, como os dados necessários ao funcionamento do serviço são tratados.

Dados tratados

Podemos tratar dados de identificação e conta, como nome, nome de usuário e endereço de e-mail, além dos dados financeiros que o próprio usuário decide registrar, como contas, lançamentos, receitas, despesas, recorrências, cartões, compras, parcelas, orçamentos e informações de planejamento financeiro.

Finalidade

Os dados são utilizados para autenticação, gerenciamento da conta e do grupo financeiro, funcionamento das funcionalidades do CashFlow, cálculos de balanço, projeções e demais recursos solicitados pelo usuário.

Armazenamento e segurança

Os dados necessários ao funcionamento do serviço são armazenados em infraestrutura do CashFlow e são transmitidos por conexão segura HTTPS. Não vendemos dados pessoais ou financeiros dos usuários.

Compartilhamento

O CashFlow não compartilha dados pessoais ou financeiros com terceiros para publicidade ou marketing. Prestadores de infraestrutura estritamente necessários ao funcionamento técnico do serviço podem processar dados sob as medidas de segurança aplicáveis.

Exclusão

O usuário pode solicitar a exclusão da conta e dos dados associados conforme as instruções disponíveis na página de exclusão de conta.

Contato

Para questões sobre privacidade, utilize o canal de contato do desenvolvedor informado na página do CashFlow no Google Play.
